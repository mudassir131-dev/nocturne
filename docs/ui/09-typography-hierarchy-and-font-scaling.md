# UI Spec 09: Typography Hierarchy & Non-Linear Font Scaling Contracts

## Type Scale
- Track Title: `headlineSmall` (24sp), bold weight, max 2 lines with marquee fallback.
- Artist/Album: `titleMedium` (16sp), medium weight with secondary alpha (0.7f).
- Lyrics: `headlineMedium` (28sp), bold weight with dynamic blur on inactive lines.
