# FAQ: Why does Nocturne use pure Jetpack Compose instead of XML views?

## Question
Why does Nocturne use pure Jetpack Compose instead of XML views?

## Answer
Jetpack Compose enables a 100% declarative UI with unidirectional data flow (UDF). It completely eliminates view binding boilerplate, layout inflation overhead, and fragment lifecycle complexity, while making dynamic theming (Aurora and Monet palettes) and fluid gestures effortless.
