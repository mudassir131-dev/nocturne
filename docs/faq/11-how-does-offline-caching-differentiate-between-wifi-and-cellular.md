# FAQ: How does offline caching differentiate between Wi-Fi and cellular?

## Question
How does offline caching differentiate between Wi-Fi and cellular?

## Answer
Nocturne monitors Android ConnectivityManager network capabilities. Users can configure the app to download high-bitrate Opus (256kbps) and cache tracks only when connected to unmetered Wi-Fi, while switching to medium quality (128kbps) or disabling automated preloading on cellular connections.
