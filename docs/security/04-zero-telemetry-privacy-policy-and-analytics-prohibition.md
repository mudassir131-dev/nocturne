# Security & Privacy Policy 04: Strict Zero-Telemetry Policy and Third-Party Tracker Prohibition

## Architectural Prohibition
- No third-party analytics SDKs (e.g., Firebase Analytics, Google Analytics, AppsFlyer) are permitted in the Nocturne codebase.
- No crash reporters that upload user data to external servers without explicit manual export.
- Network requests are restricted strictly to media streaming and metadata retrieval.\n
