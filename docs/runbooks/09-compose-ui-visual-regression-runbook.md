# Runbook 09: Jetpack Compose Visual Screenshot Regression

## Objective
Systematic procedure for validating UI consistency across Nocturne themes, dynamic color palettes, and font scale factors.

## Visual Checklist
1. Render Apple Music Player screen under light, dark, and AMOLED modes.
2. Verify Aurora dynamic shader background rendering without banding artifacts.
3. Validate typography layout integrity under system 1.3x and 1.5x font scale accessibility settings.
4. Confirm collapsible top bars smoothly collapse without layout jumping.
